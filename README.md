# 🎮 Rock Paper Scissors Lizard Spock

A modern and fully responsive implementation of the classic **Rock Paper Scissors Lizard Spock** game built with **HTML, CSS, and Vanilla JavaScript**.

The game features smooth animations, responsive layouts, score persistence using LocalStorage, and an interactive user experience inspired by the Frontend Mentor challenge.
