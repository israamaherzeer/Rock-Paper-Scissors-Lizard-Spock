# 🎮 Rock Paper Scissors Lizard Spock

A modern and fully responsive implementation of the classic **Rock Paper Scissors Lizard Spock** game built with **HTML, CSS, and Vanilla JavaScript**.

The game features smooth animations, responsive layouts, score persistence using LocalStorage, and an interactive user experience inspired by the Frontend Mentor challenge.

## ✨ Features

* 🎮 Rock • Paper • Scissors • Lizard • Spock gameplay
* 📱 Fully responsive design
* 💾 Score saved using LocalStorage
* 🎨 Modern animated interface
* ⚡ Smooth transitions and interactions
* 📖 Rules modal
* 🔁 Play Again functionality
* 🖥️ Cross-browser compatible

## ▶️ Running Locally

Clone the repository:

```bash
git clone https://github.com/israamaherzeer/Rock-Paper-Scissors-Lizard-Spock.git
```

Open the project folder and launch **index.html** in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code.
